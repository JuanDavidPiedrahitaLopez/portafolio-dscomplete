# CV — placeholder

El botón "Descargar CV" del Hero descarga un archivo distinto según el
idioma activo del sitio:

- `juan-david-piedrahita-lopez-cv.pdf` — versión en español (`es`).
- `juan-david-piedrahita-lopez-cv-en.pdf` — versión en inglés (`en`).

Ambos son PDFs de una sola página generados automáticamente como
marcador de posición (para que el botón funcione desde ya). Ninguno de
los dos es un CV real.

Para reemplazarlos:

1. Coloca tus CV reales en esta misma carpeta con los mismos nombres de
   archivo, o
2. Usa otros nombres y actualiza `cvPath.es` / `cvPath.en` en
   `src/config/site.js`.
